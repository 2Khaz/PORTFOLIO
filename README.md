# PORTFOLIO

게임 기획자 포트폴리오 사이트 구축 프로젝트.

현재 단계: **기획 문서 작성 완료 / 구현 착수 전**

## 문서

| 파일 | 대상 | 용도 |
| --- | --- | --- |
| [`docs/PORTFOLIO_MASTER_PLAN.md`](docs/PORTFOLIO_MASTER_PLAN.md) | AI 에이전트 | 실행용 상세 명세 — 데이터 스키마(Zod), 기능 수용기준(F-01~F-16), 태스크(T-01~T-35), 품질 게이트, 단계별 실행 프롬프트 |
| `docs/포트폴리오_구축_기획서.docx` | 사람 | 시각 요약본 — 비교표, 흐름도, 간트 차트, 리스크 히트맵, 체크리스트 |

두 문서는 같은 내용을 다루지만 밀도와 형식이 다릅니다. 방향을 잡을 때는 DOCX를, 실제 구현을 맡길 때는 MD를 사용합니다.

## 요약

레퍼런스 사이트(`neip2202-oss.github.io/portfolio_googleai`)의 배포 원본 소스를 정적 분석하여
계승할 강점 8가지와 개선할 약점 13가지를 도출하고, 이를 반영한 자체 구현 플랜을 작성했습니다.

**핵심 결정**

- 콘텐츠 관리: **Git 기반** (MDX/JSON 파일 + 커밋) — 레퍼런스의 치명적 보안 약점 4건이 구조적으로 소멸
- 기술 스택: **미정** — 3안 비교표 검토 후 결정 (권장: Next.js + Vercel)
- 계승할 핵심 기능: **기업별 맞춤 링크** (`?company=`) — Git 기반으로 재설계 + 만료·마스킹 추가
