# 자기소개서 페이지 수정 플랜 (+ 진행 현황)

## 1. 완료된 것 (허브 / 이력서)

- **허브(index.html)**: 이력서 버튼 강조(is-primary), 출시 경험을 참여 프로젝트보다 앞에 배치 + 하이라이트, 최상단 이력서/자소서/포트폴리오 리본 메뉴(doctabs) 추가, 기술 키워드에 `#` 접두어, 하단 연락처에 이메일 + 전화번호(010-4038-4198) 추가.
- **이력서(resume.html)**: 신상명세 바로 다음에 프로젝트 섹션 배치, 경력·학력을 신상명세 수준의 작은 리스트(`.rows`)로 병합, 스프레드시트/AI 활용 항목에 `.todo-fill` 표시로 "구체 사례 채워달라"는 안내 문구 추가(인쇄 시 자동 숨김), 하단 연결 버튼을 자기소개서 하나로 축소.
- **자기소개서 → 포트폴리오, 포트폴리오 → 이력서**: 하단 연결 버튼을 각각 하나씩만 남겨 이력서→자소서→포트폴리오→이력서 순환 구조 완성.
- **자기소개서 질문 크게**: `.qa__q` 폰트 크기를 `clamp(19px,2.6vw,24px)` → `clamp(23px,3.4vw,32px)`, `font-weight` 600→700으로 키우고, 문항 번호 배지(`.qa__no`)도 26px→30px로 함께 확대해 질문이 답변보다 뚜렷하게 보이도록 했습니다.

## 2. 보류 — 자료가 없어 임의로 진행하지 않은 부분

요청 중 아래 두 가지는 참고할 자료가 실제로 업로드되어 있지 않아 추측으로 진행하지 않았습니다.

### (1) "필요 내용 강조는 예시 화면 참고"
저장소 업로드 폴더를 확인했지만 이력서 PDF와 DESIGN.md 외에 새로 첨부된 이미지나 화면 캡처는 없었습니다. 어떤 화면을 기준으로 강조 방식을 맞춰야 하는지 알 수 없어 임의로 스타일을 바꾸지 않았습니다.

- 지금 자기소개서에는 이미 두 가지 강조 장치가 있습니다: 문장 중 핵심 키워드에 붙이는 `.mark`(밑줄/배경), 문항의 결론 문장을 뽑아 보여주는 `.qa__pull`(인용 박스).
- "필요 내용"이 무엇을 가리키는지(질문 자체? 핵심 답변 문장? 강조 색상?) 확인해 주시면 그에 맞춰 바로 반영하겠습니다.

### (2) "헤드 확인해서 수정 (강사님 피드백)"
"헤드"가 무엇을 가리키는지(페이지 상단 `.pagehead` 영역인지, 각 문항의 질문 헤드라인 `.qa__q`인지, 사이트 전체 헤더 `nav`인지)와, 강사님이 실제로 어떤 피드백을 주셨는지가 대화에 전달되지 않았습니다.

**확인 부탁드립니다** — 아래 중 어느 것에 가까운가요?

1. 페이지 상단(`.pagehead`)의 문구·구성을 피드백대로 수정
2. 각 문항 제목(`.qa__q`)의 표현/문구를 피드백대로 수정
3. 사이트 공통 헤더(로고/네비게이션)를 피드백대로 수정
4. 그 외 — 피드백 원문이나 캡처를 공유

피드백 원문이나 캡처를 올려주시면 그대로 반영하겠습니다.
