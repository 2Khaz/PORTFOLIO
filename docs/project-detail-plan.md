# 프로젝트 상세 페이지 개편 플랜

> 작성 2026-11-13 · 대상 `portfolio.html`의 게임 프로젝트 상세 (다녀가용 · 컴스톡 · 타일시공마스터)
> 상태: **계획만 정리함 — 아직 구현 전**

---

## 1. 목표

포트폴리오 카드를 눌렀을 때 나오는 상세 화면을 다음 세 가지로 정리한다.

1. **PV 영상이 배경인 메인 화면** — 들어오자마자 게임이 무엇인지 보이게.
2. **게임 플레이 버튼** — 출시한 게임은 바로 해볼 수 있게.
3. **프로젝트 이력 / 작업내역** 두 갈래로 내용 확인
   - 프로젝트 이력 = 프로젝트 전체 타임라인 + 그 시점에 내가 한 일
   - 작업내역 = 내 작업만 STAR(상황 · 과업 · 수행 · 결과)로 정리

원칙: **뎁스는 최소한**(목록 → 상세 1단계, 상세 안에서는 탭/스크롤로만 이동), **보기 좋게 꾸미기**.

## 2. 화면 구성

```
┌──────────────────────── 상단 리본메뉴 (기존) ────────────────────────┐
│                                                                      │
│   [PV 영상 — 화면 전체 배경, 소리 없이 자동 반복 재생]                 │
│                                                                      │
│     ← 포트폴리오 목록                                                 │
│                                                                      │
│     다녀가용                                    (게임명, 크게)        │
│     성장·보스 시스템 기획 · 그래픽·사운드 검수 · OBT 설계  (한 줄 소개) │
│     [인크리멘탈] [2026.09 – 2026.11] [팀 5인] [팀장?]     (태그)       │
│                                                                      │
│     [ ▶ 게임 플레이 (itch.io) ]  [ Steam 준비중 ]  [ 🔊 PV 소리 켜기 ]  │
│                                                                      │
│                              ⌄ 아래로                                 │
├──────────────────────────────────────────────────────────────────────┤
│   [ 프로젝트 이력 ]  [ 작업내역 ]        ← 탭 (스크롤하면 위에 붙음)  │
├──────────────────────────────────────────────────────────────────────┤
│   (선택한 탭의 내용)                                                  │
└──────────────────────────────────────────────────────────────────────┘
```

### 2-1. 메인(히어로)

| 항목 | 내용 |
|---|---|
| 크기 | 화면 높이 꽉 채움(`100svh - 상단메뉴`), 좌우는 화면 끝까지(full-bleed) |
| 배경 | PV 영상 `object-fit: cover`, 음소거·자동재생·반복. 모바일은 가벼운 버전 또는 포스터 이미지 |
| 가독성 | 글자가 놓이는 왼쪽 아래에만 어두운 막(단색 반투명, **그라데이션 금지**) |
| 글자 | 게임명(가장 큼) → 한 줄 소개 → 태그(장르 · 기간 · 팀 규모 · 팀장일 때만 "팀장") |
| 버튼 | ① 게임 플레이(주 버튼, 파랑 채움) ② Steam 준비중(점선, 비활성) ③ PV 소리 켜고 보기(영상 소리 켜기 + 처음부터 재생) |
| 미출시 게임 | 게임 플레이 버튼 자리 대신 "미출시" 표시 또는 GitHub 저장소 링크(보조 버튼) |
| 아래로 | 하단 가운데 작은 화살표 → 누르면 탭 영역으로 부드럽게 이동 |

### 2-2. 탭: 프로젝트 이력 / 작업내역

- 히어로 바로 아래 두 개짜리 탭. 스크롤하면 상단메뉴 바로 밑에 붙어서 따라옴(sticky).
- 탭 전환은 같은 페이지 안에서만(새 페이지·새 뎁스 없음). 주소에 `#danyeogayong/timeline`, `#danyeogayong/work` 처럼 남겨 공유 가능하게.
- 이력서·자기소개서의 왼쪽 목차와 같은 파랑(`--accent`) 계열로 통일.

### 2-3. 프로젝트 이력 (전체 타임라인)

프로젝트가 **어떻게 진행됐는지**와 **그때 내가 무엇을 했는지**를 한 줄에 같이 보여준다.

```
 2026.09 ●── 기획 착수
          │   프로젝트 │ 팀 구성, 장르를 인크리멘탈로 확정, 목표 범위 합의
          │   내 작업  │ 성장 데이터 구조 초안 작성            [작업내역 01 →]
          │
 2026.10 ●── 프로토타입 · 밸런스
          │   프로젝트 │ 핵심 루프 구현, 내부 플레이 테스트
          │   내 작업  │ 성장 곡선 비교표, 보스 전투 규칙       [작업내역 02 · 03 →]
          │
 2026.11 ●── OBT · 출시
              프로젝트 │ itch.io 공개, Steam 페이지 준비
              내 작업  │ OBT 테스트 케이스 35건 설계 및 검수     [작업내역 06 →]
```

- 세로 타임라인(왼쪽 날짜 · 가운데 점과 선 · 오른쪽 카드).
- 카드 안에 **프로젝트**(회색 라벨)와 **내 작업**(파랑 라벨)을 두 줄로 구분.
- "내 작업" 옆 링크를 누르면 작업내역 탭의 해당 카드로 이동(같은 페이지 안).
- 마일스톤(기획 확정 · 장르 전환 · 출시 등)은 점을 크게/색을 진하게.

### 2-4. 작업내역 (STAR)

내 작업만 카드로 나열. 카드 하나 = 작업 하나.

```
┌ 01 · 성장 데이터 정리 ─────────────────────── 2026.09 · 데이터/밸런스 ┐
│  ┌ 상황 S ─────────────┐  ┌ 과업 T ─────────────┐                    │
│  │ …                    │  │ …                    │                    │
│  └──────────────────────┘  └──────────────────────┘                    │
│  ┌ 수행 A ─────────────┐  ┌ 결과 R ─────────────┐                    │
│  │ …                    │  │ 핵심 수치 강조        │                    │
│  └──────────────────────┘  └──────────────────────┘                    │
│  배운 점: … (한 줄)                                                     │
│  [ 작업본 보기 ▾ ]  ← 펼치면 표·이미지(현재 work-sample) 노출           │
└──────────────────────────────────────────────────────────────────────┘
```

- PC는 2×2, 모바일은 S→T→A→R 세로.
- 결과(R)는 숫자·산출물을 굵게/파랑으로 강조.
- 표·이미지 같은 증거 자료는 기본 접힘 → "작업본 보기"로 펼침(뎁스를 늘리지 않고 길이만 줄이는 용도).
- 상단에 작은 칩으로 작업 바로가기(01 데이터 정리 · 02 밸런스 비교 …) — 현재 `project-stages`를 재사용.

## 3. 꾸미기 가이드 (사이트 공통 톤 유지)

- 색: 기존 토큰만 사용 — 파랑 `--accent #3568ac`, 옅은 파랑 `--accent-wash`, 잉크 `--ink`, 회색 `--mist/--cloud`.
- **그라데이션 사용 금지**(배경·막 모두 단색 반투명).
- 영어 사족 금지(장식용 영어 라벨 X, 도구·서비스명만 허용).
- 카드: 흰 바탕 + 얇은 테두리 + 둥근 모서리 16px, 호버 시 테두리 파랑.
- 움직임: 탭 전환 페이드 0.2초, 타임라인 점은 스크롤로 들어올 때 살짝 나타남(움직임 줄이기 설정 시 생략).
- 글자 크기: 게임명 clamp(40–72px), 섹션 제목 h2, 본문 15–16px.

## 4. 기존 내용 옮기는 방법

현재 `portfolio.html` 상세는 단계별로 **상황 · 행동 · 결과 · 배울점**(25개 항목)과 작업본(`work-sample`)으로 되어 있다.

| 현재 | 새 구조 |
|---|---|
| 상황 | **S 상황** (그대로) |
| (없음) | **T 과업** — 새로 작성. 상황 문단에서 "내가 맡은 목표/책임" 부분을 분리해 1~2문장 |
| 행동 | **A 수행** (그대로) |
| 결과 | **R 결과** (그대로, 수치 강조만 추가) |
| 배울점 | 카드 하단 "배운 점" 한 줄 |
| work-sample (표/이미지) | "작업본 보기" 접힘 영역 |
| 단계 칩(project-stages) | 작업내역 상단 바로가기 칩 |
| 확인 범위 / 자료에서 확인 / 추가할 증거 | 공개 페이지에서 제외, 필요하면 HTML 주석으로만 보관 |

**프로젝트 이력(전체 타임라인)은 새로 작성해야 함** — 프로젝트 전체 진행 단계와 날짜는 현재 페이지에 없음.

`projects/animation-pipeline.html`(컴스톡 애니메이션 파이프라인 단독 페이지)은 컴스톡 작업내역 카드 하나로 합쳐 뎁스를 줄인다.

## 5. 프로젝트별 준비물 체크리스트

| 항목 | 다녀가용 | 컴스톡 | 타일시공마스터 |
|---|---|---|---|
| PV 영상(가로 16:9, 가능하면 1080p) | ☐ (임시: 녹화본 21초) | ☐ (임시: 플레이 영상) | ☐ (임시: 플레이 영상) |
| 게임 플레이 링크 | ☐ itch.io 주소 · Steam 준비중 | ☐ itch.io 주소 | 미출시 (GitHub 저장소 있음) |
| 한 줄 소개 · 태그(장르 · 기간 · 팀 규모 · 팀장 여부) | 장르·기간 있음, 팀 규모 ☐ | 장르·기간 있음, 팀 규모 5인 | 장르·기간·팀장 있음, 팀 규모 ☐ |
| 프로젝트 이력(단계 · 날짜 · 팀 진행 · 내 작업) | ☐ 새로 작성 | ☐ 새로 작성 | ☐ 새로 작성 |
| 작업내역 STAR — T(과업) 작성 | ☐ 6건 | ☐ 6건 | ☐ 5건 |

파사도감 · 게임 랭킹 대시보드(게임이 아니거나 PV가 없음)는 히어로 배경을 대표 이미지로 대체하고, 나머지 구조(이력 / 작업내역)는 동일하게 적용.

## 6. 구현 순서

1. **틀 만들기** — 다녀가용 한 개로 히어로 · 탭 · 타임라인 · STAR 카드 스타일과 동작을 먼저 완성.
2. **기존 내용 이전** — 다녀가용 6개 항목을 STAR로 옮기고 T(과업) 초안 작성 → 확인받기.
3. **프로젝트 이력 작성** — 진행 단계·날짜를 받아 타임라인 채우기.
4. **나머지 게임 적용** — 컴스톡(애니메이션 파이프라인 페이지 합치기 포함) → 타일시공마스터.
5. **비게임 프로젝트** — 파사도감 · 게임 랭킹 대시보드에 이미지 히어로 버전 적용.
6. **실제 PV · 링크 교체** — 받는 대로 임시 영상·`href="#"` 교체.
7. **점검** — PC 3해상도(1920×1080 · 1440×900 · 1366×768)와 모바일, 인쇄 레이아웃, 영상 용량(페이지당 10MB 이하 목표).

## 7. 완료 기준

- 카드를 누르면 PV가 화면 전체 배경으로 바로 재생되고, 게임명·버튼이 첫 화면에 다 보인다.
- 출시한 게임은 버튼 한 번으로 플레이 페이지가 새 탭에서 열린다.
- 탭 두 개로 프로젝트 이력 / 작업내역을 오가며, 그 외 추가 페이지 이동이 없다.
- 타임라인의 "내 작업" 링크 → 작업내역 해당 카드로 이동한다.
- 모든 작업내역 카드가 S · T · A · R 네 칸을 갖고, 결과에 산출물/수치가 드러난다.
- 그라데이션·장식용 영어 없음, 모바일에서 가로 스크롤 없음.
